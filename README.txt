НАКРИЧИ ЗА РЕБЁНКА v8 — PRESENTER MODE

Теперь игра разделена на 3 экрана:

1) /control
Панель диджея на ноутбуке.
Есть кнопки:
- СТАРТ
- СБРОС
- НОВАЯ КОМНАТА
- УБРАТЬ УЧАСТНИКОВ
- ОТКРЫТЬ ЭКРАН ДЛЯ ПРОЕКТОРА

Диджей видит участников, громкость и состояние игры.

2) /screen?room=XXXX
Чистый демонстрационный экран для проектора/телевизора.
Там нет управляющих кнопок.
До старта: QR + набор команд 3/3.
После старта: трасса.
При старте: обратный отсчёт.
На финише: победившая команда.

3) /join/XXXX
Телефоны участников — как раньше.

КАК ИСПОЛЬЗОВАТЬ:
- открыть сайт: он автоматически отправит на /control;
- подключить проектор в Windows в режиме «Расширить эти экраны»;
- нажать «ОТКРЫТЬ ЭКРАН ДЛЯ ПРОЕКТОРА»;
- перетащить открывшееся окно на проектор;
- на проекторе включить F11;
- на ноутбуке оставить панель диджея;
- управлять игрой только с ноутбука.

Состав игры по-прежнему строго 3 на 3.
Длинная трасса x3 и мультяшные карапузы сохранены.

Для обновления загрузи ВСЕ файлы архива в корень GitHub-репозитория и Commit changes.
