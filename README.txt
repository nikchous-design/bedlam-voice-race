BEDLAM VOICE RACE v3 MULTI

Теперь одновременно могут подключаться до 12 разных телефонов.
Все участники сканируют один и тот же QR.
Каждый телефон получает свой уникальный clientId.
При временном обрыве связи телефон переподключается к своему игроку, а не создаёт дубль.

Загрузи все 6 файлов прямо в корень GitHub и замени старые:
package.json
server.js
host.html
join.html
styles.css
README.txt

Render:
Build Command: npm install
Start Command: npm start
